# SOC 2 SDLC Practice

This repository is created to practise SDLC and Change Management controls.

Sample Change: CR-002 – Password Reset Feature
## CR-002 – Password Reset Feature

### Development Details
Feature: Password reset functionality
Change Type: Application Enhancement
Developer: Demo Developer

### Implementation
- Add password reset option.
- Validate registered user email.
- Send password reset link.
- Allow users to create a new password.
